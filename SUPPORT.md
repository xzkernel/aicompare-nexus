# Support

## Documentation

Check the [README](./README.md) and the guides in [`docs/`](./docs/) first. Deployment-specific guidance is in [DEPLOY.md](./DEPLOY.md) and [docs/SELF_HOSTING.md](./docs/SELF_HOSTING.md).

## Questions and bug reports

Search existing [GitHub issues](https://github.com/xzkernel/aicompare-nexus/issues) before opening a new report. Use the appropriate issue form and include reproduction steps, browser and operating-system details, deployment method, and relevant sanitized logs.

Do not include provider keys, environment values, request headers, prompts containing private data, or other credentials. Provider account, quota, model-access, and billing questions should be directed to that provider.

Support is provided by maintainers and contributors on a best-effort basis; no response-time guarantee is offered.

## Security and conduct

Report vulnerabilities through the private process in [SECURITY.md](./SECURITY.md), never through a public issue.

For a private Code of Conduct report, contact a maintainer listed in the [README](./README.md) using a private contact method published on that maintainer's GitHub profile. Do not post sensitive conduct reports publicly.
