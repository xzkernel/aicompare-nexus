# DEPRECATED

This directory contains a **legacy FastAPI scaffold** from an earlier project layout.

**Use `backend/` instead** — it is the canonical ModelWise API:

- Streaming compare (`/api/v1/stream`)
- Dynamic model registry (`/api/v1/models`)
- Provider abstraction (OpenAI, Google, Anthropic, OpenRouter, custom)

Do not add features here. This folder may be removed in a future release.
